Build an agentic AI system for data analysis构建用于数据分析的智能体（Agentic）AI 系统

An agent is a language model in a loop: it chooses an action, a tool runs it, and the result goes back to the model until the job is done. This guide builds one that analyzes your CSV files, in about 100 lines of Python.智能体就是放进循环里的大语言模型：它选择一个动作，由工具执行，结果再返回给模型，直到任务完成。本指南用大约 100 行 Python 构建一个能分析你的 CSV 文件的智能体。

1. The idea1. 核心思想

A normal chatbot answers once. An agent keeps going. Step through a sample run below to see the loop: the model decides, a tool acts, and the result returns to the model.普通聊天机器人只回答一次，而智能体会持续工作。下面逐步查看一次示例运行，就能看懂这个循环：模型做决定，工具执行，结果返回给模型。

Model decides模型决策
Tool runs工具执行
Result returns结果返回

Everything else in this guide supports that loop: tools give the model abilities, the system prompt gives it habits, and guardrails keep it safe and affordable.本指南的其余内容都是为这个循环服务的：工具赋予模型能力，系统提示词塑造它的习惯，安全护栏让它保持安全且花费可控。

Agent or direct prompt?智能体还是直接提示？

Before building, it helps to know what an agent adds. With direct prompting, you drive: you ask, the AI answers once, and you decide the next step. With an agent, the AI drives: you give it a goal, and it decides the steps, uses tools, checks the results, and continues until it finishes or hits a limit.构建之前，先弄清楚智能体多了什么。直接提示时由你主导：你提问，AI 回答一次，下一步由你决定。使用智能体时由 AI 主导：你给出目标，它自己决定步骤、使用工具、检查结果，并持续工作，直到完成或达到上限。

Example. With direct prompting, you paste a summary of your data and ask what predicts price; if the AI needs to check missing values, you notice, ask, and paste more. You are the loop. With an agent, you hand over the CSV and the same question, and it inspects the file, runs a correlation, fits a regression, fixes its own code when it errors, and writes up the findings.例子。直接提示时，你粘贴一份数据摘要，问什么能预测价格；如果 AI 需要检查缺失值，得由你发现、追问、再粘贴更多内容。你自己就是那个循环。使用智能体时，你交出 CSV 和同样的问题，它会检查文件、计算相关性、拟合回归、在代码报错时自行修复，并写出结论。

Trade-offs. Agents are not simply better. They cost more (many model calls per task), can make a wrong early decision and build on it, and can take real actions such as running code, so they need guardrails (see step 6). Direct prompting is cheaper, easier to control, and often enough when you want to review each step yourself.取舍。智能体并不一定更好。它们成本更高（每个任务要多次调用模型），可能早早做出错误决定并在此基础上继续，还能执行运行代码这类真实操作，因此需要护栏（见第 6 步）。直接提示更便宜、更容易控制，当你想亲自检查每一步时往往就够用了。

Rule of thumb: use direct prompting for a single question or when you want to steer closely. Use an agent when the task has many steps, needs real tools or data, and you can verify the final result.经验法则：单个问题，或想紧密把控时，用直接提示。任务步骤多、需要真实工具或数据、且你能核验最终结果时，用智能体。

3. Define tools3. 定义工具

Tools are the agent's hands. Start with two. Clear names and descriptions matter more than anything else here, because the model reads them to decide what to call.工具就是智能体的双手。先从两个开始。清晰的名称和描述比其他任何因素都重要，因为模型要靠阅读它们来决定调用哪个工具。

Tool工具What it does作用
inspect_dataLoads the CSV into df and reports shape, column types, missing values, and the first rows, so the model never guesses column names.把 CSV 加载到 df，并报告形状、各列类型、缺失值和前几行，这样模型就不必猜测列名。
run_pythonRuns code in a namespace that persists between calls, so later steps build on earlier ones. Errors return as text and the model usually fixes its own bug.在一个会在多次调用之间保留状态的命名空间中运行代码，因此后续步骤可以建立在前面的结果之上。错误会以文本形式返回，模型通常能自己修复 bug。

Each entry in TOOLS has three fields: name (the label the model uses to ask for it), description (plain English the model reads to decide when to use it), and input_schema (the arguments it takes). Inside the schema, "properties": {"path": {"type": "string"}} means "one argument called path, and it is text," while "required": ["path"] says the model must supply it.TOOLS 中的每一项有三个字段：name（模型用来请求该工具的名称）、description（模型阅读的普通语言说明，用来判断何时使用它）和 input_schema（它接受的参数）。在 schema 中，"properties": {"path": {"type": "string"}} 表示“有一个名为 path 的参数，类型是文本”，而 "required": ["path"] 表示模型必须提供它。

The model never runs anything itself. It replies with a request such as {"name": "run_python", "input": {"code": "print(1)"}}, your code runs the matching function with **input (which turns the dictionary into named arguments), and you send the output back as a tool result.模型本身从不运行任何东西。它只会回复一个请求，例如 {"name": "run_python", "input": {"code": "print(1)"}}；你的代码用 **input（把字典展开为命名参数）运行对应的函数，再把输出作为工具结果发回去。

data_analysis_agent.py (part 1)
import contextlib, io, sys, traceback
import anthropic, pandas as pd, numpy as np

client = anthropic.Anthropic()
MODEL = "claude-sonnet-4-6"
MAX_STEPS = 20
MAX_CHARS = 4000
NAMESPACE = {"pd": pd, "np": np}

TOOLS = [
  {"name": "inspect_data",
   "description": "Load a CSV into `df`; return shape, dtypes, missing counts, head.",
   "input_schema": {"type": "object",
     "properties": {"path": {"type": "string"}}, "required": ["path"]}},
  {"name": "run_python",
   "description": "Run Python with persistent state (pd, np, df). Use print().",
   "input_schema": {"type": "object",
     "properties": {"code": {"type": "string"}}, "required": ["code"]}},
]

def trunc(s):
    return s if len(s) <= MAX_CHARS else s[:MAX_CHARS] + "\n...[truncated]"

def inspect_data(path):
    df = pd.read_csv(path)
    NAMESPACE["df"] = df
    return trunc(f"shape: {df.shape}\n{df.dtypes}\n{df.isna().sum()}\n{df.head().to_string()}")

def run_python(code):
    buf = io.StringIO()
    try:
        with contextlib.redirect_stdout(buf):
            exec(code, NAMESPACE)
    except Exception:
        return trunc(buf.getvalue() + traceback.format_exc())
    return trunc(buf.getvalue()) or "(no output; use print())"
Running model-written code with exec is risky on a machine you care about. Use Google Colab, a container, or run it in the browser (see step 8).在你重视的电脑上直接用 exec 运行模型写的代码是有风险的。请使用 Google Colab、容器，或在浏览器中运行（见第 8 步）。

4. Write the loop4. 编写循环

This is the whole agent. Send the conversation, run any tool the model asks for, append the results, and repeat. Stop when the model answers without requesting a tool, or when you hit the step limit.这就是整个智能体：发送对话，运行模型请求的工具，追加结果，然后重复。当模型不再请求工具而直接作答，或达到步数上限时停止。

data_analysis_agent.py (part 2)
def run_tool(name, args):
    # Dispatcher: pick the Python function matching the tool name
    if name == "inspect_data":
        return inspect_data(**args)
    if name == "run_python":
        return run_python(**args)
    return f"Unknown tool: {name}"   # the model reads this and can correct itself

def analyze(path, question):
    messages = [{"role": "user",
                 "content": f"Dataset: {path}\nQuestion: {question}"}]
    for step in range(MAX_STEPS):
        resp = client.messages.create(
            model=MODEL, max_tokens=4000,
            system=SYSTEM_PROMPT, tools=TOOLS, messages=messages)
        messages.append({"role": "assistant", "content": resp.content})

        if resp.stop_reason != "tool_use":
            return "".join(b.text for b in resp.content if b.type == "text")

        results = []
        for b in resp.content:
            if b.type == "tool_use":
                print(f"[step {step+1}] {b.name}")
                results.append({"type": "tool_result",
                                "tool_use_id": b.id,
                                "content": run_tool(b.name, b.input)})
        messages.append({"role": "user", "content": results})
    return "Stopped: step limit reached."

if __name__ == "__main__":
    print(analyze(sys.argv[1], sys.argv[2]))

Run it with python data_analysis_agent.py data.csv "Which variables best predict price?" and watch the step trail print as it works.运行 python data_analysis_agent.py data.csv "Which variables best predict price?"，观察它工作时打印出的步骤轨迹。

5. System prompt5. 系统提示词

The system prompt sets the agent's habits. For data analysis, the most valuable instructions are the ones a careful statistician would follow anyway. Define SYSTEM_PROMPT above analyze.系统提示词决定智能体的习惯。对数据分析来说，最有价值的指令，就是一位严谨的统计学家本来就会遵守的那些。在 analyze 上方定义 SYSTEM_PROMPT。

SYSTEM_PROMPT = """You are a careful data analyst working in Python.
1. Call inspect_data first. Never guess column names or types.
2. Check missing values, duplicates and outliers before modeling.
3. Use run_python for all computation. The dataset is `df`.
   Print concise summaries, never whole tables.
4. Report effect sizes and uncertainty, not just p-values.
   Distinguish association from causation.
5. If the data cannot support a conclusion, say so plainly.
6. Finish with a short answer: findings, key numbers, assumptions, caveats."""

6. Guardrails6. 安全护栏

Agents act on their own, so set limits before you share one.智能体会自主行动，所以在分享之前先设好限制。

  • Step cap. MAX_STEPS stops runaway loops and runaway bills.步数上限。MAX_STEPS 可防止失控的循环和失控的账单。
  • Output truncation. One huge printed table can flood the model's context window.输出截断。一张被整个打印出来的大表可能会淹没模型的上下文窗口。
  • Sandboxing. Execute code somewhere disposable, with no network access and no private files.沙箱。在可随时丢弃的环境中执行代码，不开放网络，也不放私人文件。
  • Spending limit. Set a monthly cap in the Anthropic Console.消费上限。在 Anthropic Console 中设置每月上限。
  • Human approval. If you later add tools that send email or modify data, require a confirmation first.人工确认。如果以后添加了会发邮件或修改数据的工具，请先要求确认。
  • Untrusted content. Text inside a dataset or web page can contain instructions. Treat tool output as data, never as commands.不可信内容。数据集或网页中的文字可能包含指令。请把工具输出当作数据，而不是命令。

7. Test it7. 测试

You cannot improve what you cannot measure. Build a small test set before tuning anything.没法衡量就没法改进。在调整任何东西之前，先建立一个小型测试集。

  1. Collect 10 to 20 questions on datasets where you already know the right answer.收集 10 到 20 个问题，数据集要是你已经知道正确答案的。
  2. Plant problems in a few: duplicate rows, a wild outlier, a column that leaks the answer.在其中几个里埋入问题：重复行、极端离群值、泄露答案的列。
  3. Run the agent on all of them and record how often it is correct and how often it notices the planted problem.让智能体跑完全部，记录它答对的比例，以及它发现被埋入问题的比例。
  4. Read the step trails of the failures. Usually the fix is a clearer tool description or one more line in the system prompt.阅读失败案例的步骤轨迹。通常的解决办法是写清楚工具描述，或在系统提示词里加一行。
  5. Re-run the full set after every change so you know the change helped.每次修改后重新跑完整测试集，这样才知道修改确实有帮助。

8. Put it online8. 上线部署

GitHub Pages only hosts static files and cannot keep an API key secret, so the safe pattern has three parts:GitHub Pages 只托管静态文件，无法保密 API 密钥，所以安全的做法包含三部分：

  • A web page on GitHub Pages holds the interface and runs the loop in the browser.GitHub Pages 上的网页承载界面，并在浏览器中运行循环。
  • Pyodide (Python compiled to WebAssembly) runs the run_python tool in the visitor's browser, so the file itself stays in their browser (only the summaries your code prints are sent to the model) and nothing needs sandboxing on your side.Pyodide（编译为 WebAssembly 的 Python）在访问者的浏览器中运行 run_python 工具，因此文件本身留在他们的浏览器中（只有代码打印出的摘要会发送给模型），你这边也无需做沙箱。
  • A Google Apps Script proxy stores your API key, checks an access code, enforces a daily call cap, and forwards each request to the Anthropic API.Google Apps Script 代理保存你的 API 密钥，检查访问口令，限制每日调用次数，并把每个请求转发给 Anthropic API。

Whatever you deploy, set the spending limit first, keep the daily cap low while testing, and share the access code privately.无论部署在哪里，都要先设置消费上限，测试期间把每日调用上限调低，并私下分享访问口令。

9. Use Gemini instead9. 改用 Gemini

The same agent works with Google's Gemini API. The loop idea is identical; what changes is the package, the way tools are declared, and who runs the loop.同一个智能体也可以使用 Google 的 Gemini API。循环的思路完全一样，变化的只是所用的包、声明工具的方式，以及由谁来运行循环。

Install the google-genai package (imported with from google import genai). The older google-generativeai package still appears in many tutorials, but Google says new features are built in the new SDK. Create a key in Google AI Studio.安装 google-genai 包（导入方式为 from google import genai）。许多教程里仍然出现旧的 google-generativeai 包，但 Google 表示新功能都在新的 SDK 中开发。请在 Google AI Studio 创建密钥。

Windows PowerShell
pip install google-genai pandas numpy matplotlib scipy statsmodels
$env:GEMINI_API_KEY="your-key-here"

What changes compared with the Claude version:与 Claude 版本相比的变化：

  • Package: google-genai replaces anthropic.包：用 google-genai 取代 anthropic。
  • Tools: no TOOLS list. You pass plain Python functions, and the SDK builds the schema from each function's name, type hints and docstring.工具：不再需要 TOOLS 列表。直接传入普通 Python 函数，SDK 会根据函数名、类型提示和文档字符串生成 schema。
  • Loop: automatic function calling is the default. The SDK runs your function when the model asks and sends the result back until the model answers.循环：自动函数调用是默认行为：SDK 会在模型请求时运行你的函数，并把结果送回去，直到模型作答。
  • Step cap: MAX_STEPS becomes maximum_remote_calls.步数上限：MAX_STEPS 变成 maximum_remote_calls。
  • Dispatcher: run_tool is no longer needed, because the SDK does that job.调度函数：不再需要 run_tool，因为 SDK 已经代劳。

    """Load a CSV into df; return shape, dtypes, missing counts, head."""
    ...                      # same body as before

    """Run Python with persistent state (pd, np, df). Use print()."""
    ...                      # same body as before

def analyze(path, question):

        system_instruction=SYSTEM_PROMPT,
        tools=[inspect_data, run_python],        # plain functions

Web version. The Apps Script proxy calls generativelanguage.googleapis.com with your key in the x-goog-api-key header. 10. Automate it10. 自动化

Once started, the loop already runs by itself. What is left to automate is the setup and the starting. Three small steps cover it.一旦启动，循环本身就会自动运行。剩下需要自动化的是准备和启动。三个小步骤即可搞定。

One-click launcher. A .bat file is a text file of Windows commands that run in order when you double-click it. Save this as run.bat in your agent folder (it uses activate.bat, which avoids the PowerShell permission error):一键启动器。.bat 文件是一个包含 Windows 命令的文本文件，双击后会按顺序执行。把下面的内容保存为智能体文件夹中的 run.bat（它使用 activate.bat，可避开 PowerShell 的权限错误）：

@echo off
cd /d %~dp0
if not exist venv python -m venv venv
call venv\Scripts\activate.bat
pip install -q anthropic pandas numpy matplotlib scipy statsmodels
python run_all.py

Store your API key permanently once, then open a new terminal: setx ANTHROPIC_API_KEY "your-key-here"只需永久保存一次 API 密钥，然后打开新终端：setx ANTHROPIC_API_KEY "your-key-here"

Batch runner. Save as run_all.py. It analyzes every CSV in an inbox folder, writes a report to reports, and skips files already done:批量运行器。保存为 run_all.py。它会分析 inbox 文件夹中的每个 CSV，把报告写入 reports，并跳过已完成的文件：

import glob, os
from data_analysis_agent import analyze

os.makedirs("reports", exist_ok=True)
for path in glob.glob("inbox/*.csv"):
    out = f"reports/{os.path.splitext(os.path.basename(path))[0]}.md"
    if os.path.exists(out):
        continue
    report = analyze(path, "Check data quality, then report the most important patterns.")
    open(out, "w", encoding="utf-8").write(report)

Schedule it. Windows Task Scheduler can run the launcher daily (the computer must be on and logged in):定时运行。Windows 任务计划程序可以每天运行启动器（电脑必须开机并保持登录）：

schtasks /create /tn "DataAgent" /tr "C:\path\to\agent\run.bat" /sc daily /st 07:00
Unattended runs still spend API credit and execute model-written code. Keep the spending limit and step cap in place, only feed it files you trust, and read the first several reports before relying on them.无人值守的运行仍会消耗 API 额度，并执行模型写的代码。请保持消费上限和步数上限，只输入你信任的文件，并在依赖这些报告之前，先阅读最初的几份。

11. Glossary11. 术语表

Term术语Meaning含义
JSONA plain-text format for structured data: objects { } of key-value pairs, arrays [ ], strings, numbers, true/false, and null. Tool definitions and all API traffic use it. Python dictionaries and lists map directly onto it.一种用于结构化数据的纯文本格式：由键值对组成的对象 { }、数组 [ ]、字符串、数字、true/false 和 null。工具定义和所有 API 通信都使用它。Python 的字典和列表可以直接对应它。
f-stringA string starting with f where {value} is replaced by that value: f"Dataset: {path}". Use f"""...""" for several lines. Literal braces must be doubled: {{.以 f 开头的字符串，其中的 {value} 会被替换成该值：f"Dataset: {path}"。多行请用 f"""..."""。要输入字面的花括号必须写成双份：{{。
**argsUnpacks a dictionary into named arguments, so f(**{"code": "x"}) equals f(code="x").把字典展开为命名参数，因此 f(**{"code": "x"}) 等同于 f(code="x")。
Type hints类型提示（Type hints）Optional notes like name: str and -> str. Python ignores them when running, so you can leave them out.类似 name: str 和 -> str 的可选注释。Python 运行时会忽略它们，所以可以省略。
Trailing comma尾随逗号（Trailing comma）A comma after the last item in a list or dictionary. Python allows it; strict JSON does not.列表或字典最后一项之后的逗号。Python 允许，严格的 JSON 不允许。
Virtual environment虚拟环境（Virtual environment）A private copy of Python for one project (python -m venv venv), so its packages stay separate from everything else.为一个项目准备的独立 Python 副本（python -m venv venv），让它的包与其他一切保持分离。
.bat file.bat 文件A Windows text file of commands that runs when you double-click it.一个 Windows 文本文件，里面是一串命令，双击即可运行。
